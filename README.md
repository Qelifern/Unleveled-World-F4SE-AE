# Unleveled World - F4SE - AE

Unleveled World for Fallout 4 AE


https://www.nexusmods.com/fallout4/mods/105827




Description

Unleveles Item and Character Lists through F4SE making all Leveled Lists have Level set to 1



Requirements

F4SE - Fallout 4 - 1.11.221.0



How it works

Loops through and sets level->1 on all leveled item/character lists on 3 different event calls.

1\. When starting the game

2\. When starting a new save game

3\. When loading a save



If you have weapon mods that inject into leveled lists you need to save the game and reload the save for the injected lists to be unleveled.
